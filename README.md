# Clinic Ready – shortened edition

This project separates the shortened standalone website into editable files without changing its content or application logic.

## Open in VS Code
Extract the ZIP, then choose File > Open Folder and select clinic-ready-shortened. Preview index.html in a browser or with Live Server.

## Files
- index.html: page structure
- style.css: styling
- modules.js: module content, quizzes, references and other data
- script.js: application logic

## Update the existing GitHub Pages site
Upload the five individual files (not the enclosing folder) to the root of the existing repository, replacing the matching files. Commit to main. Keep Pages configured to main / (root). Wait for the Pages deployment to succeed. Back up the original first.
